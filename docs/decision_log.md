# Decision Log — CPI Project

## Locked design decisions (from protocol v2)

1. **Outcome scope:** broader inadequate-depth framing (sustained BIS≥60 anywhere in the case), with phase stratification (early/mid/late) as a pre-specified sensitivity analysis — not a narrowed late-case-only emergence window.

2. **Matched negative sampling:** included as a secondary design, but purely as an internal robustness/construct-validity check within the paper. Not framed as a head-to-head comparison against Qian et al.

3. **Nonlinear HR features (DFA, sample entropy):** included in both Model A and Model B.

## Phase 0 decisions

4. **Python version:** 3.13 selected (Windows environment). 3.14 ruled out — CatBoost has no working install path on 3.14 as of testing (confirmed open compatibility issue, no published wheels). 3.13 confirmed compatible with CatBoost (supported since release 1.2.8) and expected compatible with the rest of the stack (LightGBM, miceforest, neurokit2, nolds, vitaldb) based on pre-install research; actual `pip install` served as final confirmation — all libraries installed successfully.

5. **Random seed:** 2311, applied globally wherever randomness is used (splits, class-weighting in place of SMOTE, bootstrap resampling).

6. **imbalanced-learn:** installed per the original Phase 0 library list, but not used in the pipeline — SMOTE was replaced with class-weighting (decision documented separately: linear interpolation between nonlinear HR dynamics features generates physiologically impossible synthetic trajectories).

11. **Sanity-check plotting note:** naive line plots of raw (non-resampled) BIS/HR data intermittently failed to render correctly in matplotlib for some cases (blank or truncated traces), a reproducible but unresolved rendering artifact — not a data integrity issue (raw values were independently verified correct via direct array inspection in all affected cases). Resolved for visualization by resampling to a regular 5-second grid before plotting. This does not affect the raw stored data in `data/raw/`, which remains at native resolution per the Phase 2 "raw and untouched" principle.

12. **BIS coverage check (Phase 2, informing Phase 3 design):** across a sample of 100 downloaded cases, BIS coverage (active BIS duration relative to case duration, excluding BIS=0 dropout artifacts) is high — median 98.9%, mean 97.7%, only 2/100 cases below 80% coverage, 0/100 below 50%. Confirms partial-coverage cases (e.g., case 7, ~45% coverage) are outliers, not representative — Phase 3 exclusion/missingness thresholds should be informed by this distribution rather than anecdotal single-case inspection. Note: one case showed coverage slightly >100% (1.02), likely a minor BIS/HR timestamp alignment edge case, worth flagging but not immediately concerning at this sample size.

13. **Phase 3 cohort locked: 3,213 cases** (from 6,388 total VitalDB cases). Attrition: 6,388 → 6,043 (general anesthesia only) → 5,865 (exclude liver transplantation and donor hepatectomy) → 5,825 (exclude <45 min recording) → 3,213 (exclude insufficient core track availability: HR, MAP, SpO2, ETCO2, BIS, BIS/EMG).
    - **Scope note on step 3:** the guide's exclusion criterion (neurosurgical, cardiovascular, liver transplant) is only partially applicable to this dataset. VitalDB (this sample) contains no neurosurgery cases and no true cardiac surgery (its "Vascular" category is peripheral vascular surgery, not cardiac surgery with cardiopulmonary bypass; its "Thoracic surgery" department is pulmonary/thoracic oncologic surgery, not cardiac). These categories remain eligible per protocol; they are simply absent from the dataset, not excluded. The only applicable exclusion was liver transplantation and donor hepatectomy (living liver donor surgery, excluded alongside transplant recipients on Mand's instruction, despite being physiologically distinct from a transplant recipient).
    - **ASA class distribution, final cohort:** ASA I 21.2%, II 63.5%, III 14.1%, IV 0.9%, coded "6" 0.4% (11 cases, data-quality caveat below), 71 cases (2.2%) missing/NaN, retained as missing rather than imputed or excluded (ASA is descriptive only, not an exclusion criterion, per protocol).
    - **ASA=6 data-quality caveat:** 11 cases are coded ASA 6 in VitalDB, which in the standard ASA-PS scale denotes a declared brain-dead organ donor. Manual review of these 11 cases' dx/opname (7 empyema/bronchopleural-fistula debridements, 1 metastasectomy, 1 lung wedge resection, 1 incision and drainage) confirms none are organ-procurement cases — these are ordinary therapeutic thoracic-surgery patients. This is very likely a coding artifact or non-standard use of the ASA field in VitalDB's source data, not a true reflection of physical status. Report these 11 cases as a distinct "coded ASA=6 (data-quality caveat)" category in Table 1 rather than as genuine ASA VI, to avoid a factually incorrect implication (organ donor) reaching the manuscript.
    - **Selection bias (retained n=3,213 vs. excluded n=3,175), for manuscript Section 2 / Discussion:** retained cohort is measurably older (mean 58.9 vs 55.7 years), more male (55.4% vs 46.1%), and higher-ASA (ASA I 21.2% vs 36.2%; ASA III 14.1% vs 8.4%) than excluded cases. Excluded cases skew toward Colorectal (31%) and Breast (13.1%) surgery; retained cases spread more evenly across Major/Minor resection, Stomach, and Colorectal. This pattern is most plausibly driven by which surgery types/departments use BIS monitoring routinely (the track-availability exclusion, step 5) rather than by the general-anesthesia or liver-transplant exclusions. Practical implication: the model is trained on a population skewing older, more male, and higher surgical risk than the general VitalDB population — a genuine generalizability limitation, and arguably relevant context for the paper's "low-resource, pragmatic deployment" framing, since it implies real-world BIS-monitored populations may already look like this retained cohort rather than the general surgical population.
14. **Phase 4 step 1 complete: biological plausibility filtering.** Applied fixed bounds (HR 30–200, MAP 30–160, SpO2 50–100, ETCO2 10–80) to the locked 3,213-case cohort, reshaped to a 1-second resampled wide-format grid (`data/interim/`) as the working structure for all subsequent phases. Values flagged as implausible: HR 65,714 (~0.2%), ART_MBP 1,369,580 (~4.3%), SpO2 3,496 (~0.01%), ETCO2 554,323 (~1.7%). ART_MBP's higher flagging rate was verified (not assumed) against raw sample values in a 4-case check: out-of-range values cluster near-zero/negative (consistent with arterial line zeroing/flushing artifacts) with occasional high spikes (consistent with fast-flush transients) — a known, expected pattern for invasive arterial pressure monitoring, not a units or logic error. BIS, BIS/EMG, and the TCI tracks (PPF20_CE, RFTN20_CE) were left untouched in this step per protocol; BIS=0 handling is deferred to step 2 (target sanitization).

15. **Phase 4 step 2 (partial) complete: BIS sanitization.** Applied to the locked 3,213-case cohort's interim files (post-plausibility-filtering). BIS=0 (sensor-off/dropout artifact, confirmed in Phase 2 sanity check) nulled: 3,392,983 of 42,452,676 valid BIS samples (7.99%). BIS nulled due to concurrent EMG >40 dB: 1,850,568 samples (4.36%) — threshold is empirically chosen (no citable source found in Phase 1 literature review), flagged for the Phase 9 EMG-threshold sensitivity analysis per protocol. Event detection (sustained BIS≥60 runs ≥180s) deferred to after

16. **Phase 4 step 3 complete: LOCF imputation.** Applied to HR, ART_MBP, PLETH_SPO2, ETCO2, BIS on the 3,213-case cohort's 1s-grid interim files. Rule: a run of consecutive missing values is forward-filled only if the entire run is ≤15 seconds (primary cutoff; 10s/30s alternates deferred to Phase 9 sensitivity analysis); longer runs are left entirely as NaN (all-or-nothing per gap, not partial-fill — an interpretive choice since the guide's wording didn't fully specify this, confirmed reasonable). Fill rates: HR 88.6%, ART_MBP 76.9%, SpO2 91.4%, ETCO2 83.2% — high rates expected, since native sampling intervals for these tracks are typically 1-2s, so most "missing" 1-second grid points are normal between-sample gaps, not real data loss. BIS fill rate notably lower (3.9%), consistent with step 2's finding that most BIS missingness comes from long sensor-off/dropout windows (minutes, not seconds) — correctly left unfilled by the ≤15s rule rather than fabricating a flat signal across genuine physiological gaps. EMG and TCI tracks (PPF20_CE, RFTN20_CE) excluded from LOCF — EMG is an artifact-detection signal, TCI tracks are drug-infusion-derived and not treated as physiological monitoring gaps.

17. **Phase 4 step 2 correction: recovered EMG-unfiltered BIS.** Step 2's original script overwrote the BIS column in place when applying EMG>40dB filtering, violating the guide's explicit requirement to store the unfiltered version separately for the Phase 9 EMG sensitivity analysis. Recovered from `data/raw/` (undamaged, per Phase 2's "raw and untouched" principle): reconstructed a `BIS_emg_unfiltered` column (BIS=0 sensor-off artifact still nulled, but no EMG filtering applied), resampled and LOCF-imputed identically to the primary BIS column, added alongside it in `data/interim/`. Verified on a 5-case spot-check: unfiltered non-null count exceeds filtered in every case (as expected), confirming correct reconstruction.


18. **Phase 4 step 2 (v3) confirmed: SQI-based filtering validated against EMG-based filtering on this cohort.** SQI distribution (20-case sample, 277,973 valid samples): heavily skewed toward high quality (median 91.7, mean 81.2, IQR 76.9-97.4). SQI<50 flags 9.2% of all samples; SQI<15 flags 7.0% - both far more conservative than EMG>40dB's behavior. Critically, SQI<50 overlapping with BIS>=60 time (the actual test of whether a filter targets artifact vs. genuine signal): only 6.3% of BIS>=60 seconds coincide with SQI<50, vs. 63% for EMG>40dB on the same comparison - a ~10x difference. This confirms SQI-based filtering resolves the EMG/arousal confound: it removes signal-quality artifact without disproportionately deleting genuine inadequate-depth episodes. SQI<50 is locked as the primary threshold; SQI<15 (Huang et al.'s stricter precedent) remains the Phase 9 sensitivity-analysis comparator, as planned.

19. **Phase 4 step 2 (v3) rebuild complete: all BIS filter variants regenerated from raw.** `data/interim/` BIS columns rebuilt cleanly from raw data (not patched from prior steps) for the full 3,213-case cohort. Primary column `BIS` is now SQI<50-filtered (97.0% retention of BIS=0-nulled base, post-LOCF). Sensitivity comparators stored alongside: `BIS_emg40_filtered` (94.5% retention), `BIS_emg35_filtered` (93.1% retention, Kim et al. 2022 precedent), `BIS_unfiltered` (100.1% retention - slightly above base since LOCF only adds values, never removes). Raw `SQI` column also retained in interim files for diagnostics. Retention ordering (SQI > EMG40 > EMG35) is consistent with SQI being the least aggressive of the three filters, as expected from the validation in entry 18.

20. **Phase 4 step 2 (v3) event detection complete across all four BIS variants.** Sustained BIS>=60 events (>=180s), full 3,213-case cohort: SQI-primary 4,701 events (2,670/3,213 cases, 83.1%); EMG>40dB 1,914 events (1,192 cases, 37.1%); EMG>35dB (Kim et al.) 1,603 events (1,015 cases, 31.6%); fully unfiltered 5,100 events (2,790 cases, 86.9%). SQI-primary retains 95.7% of the unfiltered variant's case-level event rate, versus 42.7% (EMG40) and 36.4% (EMG35) - strong, cohort-level confirmation that SQI-based filtering preserves genuine outcome signal far better than either EMG threshold, consistent with the mechanistic finding in entries 18-19. Event/case counts saved to results/phase4_events_{sqi_primary,emg40,emg35,unfiltered}.csv for Phase 9 Hypothesis Test 3. Note for Phase 6/8: positive-case count differs substantially by label variant (2,670 vs. ~1,000-1,200), affecting class balance and effective sample size for any analysis using a non-primary label set.
